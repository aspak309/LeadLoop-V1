# LeadLoop V1
Free, local-first customer + follow-up + order workspace.

## Included
- Customer records and notes
- Follow-up reminders/status views
- Orders with courier/tracking fields
- Generic printable shipping/dispatch label
- Local IndexedDB storage
- JSON export/import backup
- Search and filters
- Responsive mobile UI

## Important
The printable label is a generic label. It is NOT an official marketplace/courier label and does not create a carrier-valid AWB/QR/barcode. Official marketplace labels should only be generated from the relevant marketplace/courier system or authorized API.

No paid AI, database, WhatsApp API or cloud service is required for this V1.
